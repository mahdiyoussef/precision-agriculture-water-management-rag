### 1. Introduction

16     In reservoir operation, present benefits must be balanced with future, uncertain ones [SOURCE: Page_3]

17   [Soncini-Sessa et al., 2007; Castelletti et al., 2008]. After each release decision, new infor- [SOURCE: Page_3]

18   mation becomes available and partially reduces uncertainty. Optimal reservoir operation [SOURCE: Page_3]

19   can be framed as a Multistage Stochastic Programming problem [Birge and Louveaux , [SOURCE: Page_3]

20   1997; Shapiro and Andrzej , 2003], which, for long horizon, is conveniently solved by [SOURCE: Page_3]

21   Stochastic Dynamic Programming [Bellman and Dreyfus, 1966]. SDP, notwithstanding [SOURCE: Page_3]

22   its elegance and potential, is affected by the so-called “curse of dimensionality”, limiting [SOURCE: Page_3]

23   its application to systems made of few variables [Stedinger et al., 1984; Trezos and Yeh, [SOURCE: Page_3]

24   1987]. In the literature, some alternatives try to circumvent these limitations, for example [SOURCE: Page_3]

25   by defining an optimal trajectory [Turgeon, 1980] or fixing the release policy family and [SOURCE: Page_3]

26   find the parameters by evolutionary algorithm [Nicklow et al., 2009; Reed et al., 2013]. [SOURCE: Page_3]

27   These solutions, even if advantageous for some aspects, have rarely been tested over large [SOURCE: Page_3]

28   systems, i.e. made of a large number of reservoirs. Stochastic Dual Dynamic Programming [SOURCE: Page_3]

29   [Pereira and Pinto, 1991] (SDDP) is an approximation of SDP that largely attenuates the [SOURCE: Page_3]

30   curse of dimensionality. SDDP, however, requires the optimization problem to be modeled [SOURCE: Page_3]

31   as linear, since problem linearity ensures cost-to-go function convexity. [SOURCE: Page_3]

32     SDDP requires identifying a linear stochastic inflow model which reproduces the stream- [SOURCE: Page_3]

33   flow process and its uncertainty. Streamflow process model identification is a critical step [SOURCE: Page_3]

34   in dynamic programming problem setting, sometimes referred to as “curse of modelling” [SOURCE: Page_3]

### 4. Conclusions and Discussion

408     SDDP, to be employed for reservoir operational rules design, requires the identification [SOURCE: Page_23]

409   of a linear streamflow process model. Presently, models from the literature use almost [SOURCE: Page_23]

410   always a periodic autoregressive model with monthly time-steps. In this study we proposed [SOURCE: Page_23]

411   an innovative streamflow process model to be used in SDDP. Model features are i) a log- [SOURCE: Page_23]

412   normal multiplicative stochastic component, which guarantees positive discharge values, [SOURCE: Page_23]

413   and ii) non-uniform time-steps, which makes the process approximately homoscedastic [SOURCE: Page_23]

414   i.e. having constant variability. The multiplicative non-linear model can be employed [SOURCE: Page_23]

415   in the SDDP forward phase directly, whereas a linearized version must be used in the [SOURCE: Page_23]

416   backward phase. We showed how to identify the multiplicative streamflow process model [SOURCE: Page_23]

417   and its linearized version, and how to derive the non-uniform time-steps lengths from [SOURCE: Page_23]

418   discharge data. Model identification for the proposed model is not more complex than [SOURCE: Page_23]

419   for classic periodic autoregressive models with monthly time-step. The proposed features [SOURCE: Page_23]

420   are independent from each other, then each of them can be applied separately. This work [SOURCE: Page_23]

421   address specific problems encountered in SDDP, but some results may have a broader [SOURCE: Page_23]

422   (potential) validity in time series modeling for synthetic streamflow sequences generation. [SOURCE: Page_23]

423     We applied the model to the streamflow process at Soukoutali, on the Senegal River, [SOURCE: Page_23]

424   for the operational rules design of a single reservoir system. Model identification would [SOURCE: Page_23]

425   not be different if the reservoirs were many. The proposed multiplicative model offers [SOURCE: Page_23]

426   a better representation of the streamflow process both in the forward phase, where it [SOURCE: Page_23]

427   correctly represents the streamflow dynamics and the discharge distribution, and in the [SOURCE: Page_23]

428   backward phase, where it correctly represents the residual distribution, avoiding the fat- [SOURCE: Page_23]

429   tail phenomenon, otherwise present in the classic Thomas-Fiering model. The model [SOURCE: Page_23]
