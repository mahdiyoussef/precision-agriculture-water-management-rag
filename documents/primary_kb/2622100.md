### 3. Illustrative examples

Package functions can be used in many ways. The cumBg() function can process more than twenty different types of measure- ments. Most functions are flexible and contain optional arguments. The vectorized basic functions exploit vector recycling rules to facilitate a wide range of operations. Due to space restraints, this section presents only a small number of limited examples.
