This paper presents a Flood Frequency Analysis (FFA), which takes into account the notion of duration : the flood- duration-frequency (QdF) method. QdF analysis is similar to the intensity-duration-frequency analysis commonly used for rainfall. The first part describes the analytical formulations. An application to the Saf-Saf River is performed. QdF curves are fitted. Synthetic Mono-Frequency Hydrographs (SMFHs) are then derived. The main advantage of these hydrographs is that all the characteristics of the SMFHs are related to the same return period. These design flood hydrographs are inputs for hydraulics modelling and simulation of sedimentation in Zardezas reservoir (Algeria). [SOURCE: Page_1]
